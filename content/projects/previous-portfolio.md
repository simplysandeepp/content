## Overview

Sandeepp.in is the previous version of my personal site — and a deliberate playground for **creative front-end and motion design**. Where this current portfolio is minimal and typographic, the previous one went the other direction: **fully 3D, immersive, and animation-heavy**, built to show off interaction and UI craft. It's a full-stack build with a premium-themed public site, a REST API backend, and a private admin dashboard.

## The Idea

I wanted a portfolio that was an experience, not just a page — something that demonstrated I could design and engineer rich, performant motion and 3D on the web, not only ship clean layouts. So I leaned into custom animations, depth, and interactivity throughout.

## What I Built

- **3D visuals & depth** — immersive 3D effects driving the look and feel
- **Custom motion design** — bespoke, choreographed animations and transitions across the site
- **Premium-themed public site** — the front-facing experience
- **REST API backend** — an Express + MongoDB API powering dynamic content
- **Private admin dashboard** — a separate authenticated surface to manage the site
- Built as a full-stack app, independently deployable

## Tech Stack

**Frontend:** React 18, TypeScript, 3D effects, Framer Motion for animation

**Backend:** Node.js, Express, REST API

**Database:** MongoDB

## Why It's Here

It's the clearest showcase of my **creative UI and animation skills** — a contrast to this minimal site, and proof I can build across the spectrum from restrained and typographic to bold and interactive.
