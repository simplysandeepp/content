## Overview

LearnLoop AI is an educational platform designed to adapt to your learning style in a premium, distraction-free environment. It combines AI-powered personalized learning with a modern web stack to make studying more engaging and effective for both students and educators.

## The Problem

Generic learning tools treat every student the same and bury them in clutter. LearnLoop AI focuses on a clean, personalized experience — surfacing what each learner needs to work on and keeping the interface distraction-free.

## What I Built

**For students**
- **AI study chatbot** for instant help while learning
- **Performance analytics** with detailed metrics and visualizations
- **Study planner** to organize the learning schedule
- **Assessments & quizzes** to evaluate understanding
- **Weak-area analysis** to identify and target topics that need work
- **Leaderboard** for motivation

**For administrators**
- User management, an analytics dashboard, content management, and system configuration

**UI/UX**
- Premium dark theme with glassmorphism and gradient accents, fully responsive, smooth Framer Motion animations

## Tech Stack

**Frontend:** Next.js 16 (React 19), TypeScript, Tailwind CSS, Framer Motion, Recharts, Lucide

**Backend:** FastAPI (Python), JWT-based auth, PostgreSQL (planned)

## Use Case

Students who want a personalized, focused study environment with AI help and progress tracking — and educators who need a dashboard to manage learners, content, and assessments.
