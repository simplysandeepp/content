| Marks | What to write (template) | Time |
|---|---|---|
| **7** | Definition (2–3 lines) → one neat diagram → 4–5 key points → one formula → one example/application | ~12 min |
| **10** | Definition → diagram → working step-by-step → formula with every symbol explained → advantages + limitations → example | ~18 min |
| **16** | Intro → full architecture diagram → each component explained → math / derivation → training algorithm → comparison table → applications → challenges → conclusion. For "design a system" questions: Problem → Data → Model → Training → Evaluation → Risks | ~30 min |

**Tip:** **Scoring tricks:** Always draw a labelled diagram (even a simple box-arrow one). Write formulas in a box. Use a comparison table wherever the question says "compare / differentiate". Underline keywords: *latent space, minimax, reparameterization, ELBO, mode collapse, self-attention, cross-attention, causal mask, chunking, top-k retrieval*.

**Tip:** **Highest-priority topics (by number of practice questions):** GAN (architecture + loss + challenges) ≫ VAE (ELBO + reparam + KL) ≫ Generative vs Discriminative ≫ Diffusion (with numerical) ≫ Transformer + Self-attention numerical ≫ cGAN / StyleGAN ≫ RAG ≫ Prompting.
