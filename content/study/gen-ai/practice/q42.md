## What's actually being asked
Design a concrete StyleGAN setup that lets a fashion studio dial facial appearance, hairstyle, pose, clothing texture, background, and fine detail independently, and justify it using style levels, style mixing, and attribute control.

## Answer

### Why StyleGAN fits this requirement
A traditional GAN gives one entangled `z` — changing anything changes everything. The studio instead needs independent handles, which is exactly what StyleGAN's per-resolution style injection provides: `z` is mapped by `f: Z → W` into `w`, which is re-injected via learned affine transforms into AdaIN modulation at **every** synthesis resolution,
`AdaIN(x_i, y) = y_{s,i} · (x_i − μ(x_i)) / σ(x_i) + y_{b,i}`,
so different resolution bands end up responsible for different attributes (see diagram above).

### Mapping studio requirements onto style levels
- **Pose and overall body/face shape** → coarse layers (4×4–8×8). These set the broad structure before any detail exists.
- **Hairstyle and facial feature structure** → middle layers (16×16–32×32). Finer than overall shape, but still structural rather than textural.
- **Clothing texture and colour, fine facial detail** → fine layers (64×64–1024×1024), where colour scheme and texture patterns live.
- **Micro detail (fabric grain, skin pores, stray hair strands)** → the explicit per-pixel noise input at each layer, independent of style, so it varies sample-to-sample without touching any semantic attribute.
- **Background** → StyleGAN doesn't give background its own clean resolution band by default, so in practice the studio would use a **per-layer latent** (the extended `W+` space — a different `w` per layer group instead of one shared `w`) and assign a distinct `w` to the layers whose receptive field dominates background content, or combine it with compositing/style mixing against a separately generated background sample.

### Style mixing as the control mechanism
To realize independent control in practice, generate two (or more) latents — e.g. `w_A` encoding a desired face/pose and `w_B` encoding a desired clothing texture/background — and feed `w_A` to the coarse (and middle) layers while feeding `w_B` to the fine layers, crossing over at a chosen resolution. This is exactly the regularization trick used during StyleGAN training (crossover at a random layer boundary, forcing adjacent styles not to be assumed correlated), repurposed at inference time for deliberate attribute transplantation: "this model's face, that outfit's texture."

### Finer attribute control
For continuous edits (e.g. "same outfit, slightly different pose"), find a direction `Δ` in `W` space correlated with that attribute (via a labelled-example regression, or unsupervised decomposition) and apply `w' = w + α·Δ`. Because `W` is more disentangled than `Z`, this moves the target attribute while leaving others comparatively undisturbed — something not achievable by perturbing `z` in a traditional GAN.

## Exam tip
Explicitly name which resolution band each studio requirement maps to — "pose is coarse, texture is fine" is the single fact examiners check for in scenario questions like this one.
