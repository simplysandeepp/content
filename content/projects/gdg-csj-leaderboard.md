## Overview

A real-time leaderboard for the **GDG Cloud Study Jam**, tracking each participant's progress through Google Cloud skill badges as it happens. Built so organizers and participants could see standings update live during the program.

## The Problem

During a Study Jam, dozens of participants complete Google Cloud skill badges at their own pace. Tracking progress manually in spreadsheets is slow and never current. This leaderboard makes progress visible and competitive in real time.

## What I Built

- **Live leaderboard** that ranks participants by completed skill badges
- **Real-time updates** powered by Supabase — standings refresh as data changes
- **Clean, responsive UI** readable on a projector or a phone
- Built and shipped fast on Vite + Vercel

## Tech Stack

**Frontend:** React, TypeScript, Tailwind CSS, Vite

**Backend / Data:** Supabase (real-time database)

**Deploy:** Vercel

## Use Case

GDG chapter organizers running a Cloud Study Jam who want a live, motivating view of participant progress.
